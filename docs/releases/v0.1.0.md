The first release of garner.

garner makes package repositories simple to set up: one binary and one YAML file. It fills them with the releases published on your forges, by your own projects and the ones you depend on, and with packages uploaded from CI. Everything is served signed with one key.

This release serves apt and dnf repositories and syncs releases from GitHub, GitHub Enterprise Server, GitLab and Forgejo/Gitea, from single repositories or whole organizations and groups.

It runs on Linux amd64 with systemd. The packages, and apt and dnf as clients, are tested on Debian 13, Ubuntu 26.04 LTS, AlmaLinux 10 and Fedora 44.

garner is in early development and is not ready for internet-facing use. Configuration and behaviour may change between 0.x releases.
